# Components Directory

This directory contains reusable React components organized by feature area.

## Structure

- **common/** - Shared components used across multiple screens
  - Buttons, inputs, cards, modals, etc.

- **practice/** - Components specific to the Practice screen
  - Tablature display, pitch detector visualization, feedback indicators, etc.

- **library/** - Components specific to the Library screen  - Tab cards, filters, import dialogs, etc.

- **settings/** - Components specific to the Settings screen
  - Setting items, sliders, toggles, etc.

## Guidelines

- Keep components small and focused on a single responsibility
- Use TypeScript for all components with proper type definitions
- Follow React Native Paper design system where applicable
- Add unit tests for complex components
- Document component props with JSDoc comments
